What's goin' on with our server?

Now, I know all you guys out there want to know all about my server, what operating system it's running, and what server it's using, but hackers also want to know that. So I'll tell you a bit about the server, but not too much. Sorry.

Server Downtime(s)

I know, web servers are supposed to be on all the time, and that is my goal. But sometimes things happen. Also, we have scheduled downtimes.

Maintenance

Every night, from 00:00 to (hopefully) no later than 03:00, the server will defragment the disks and perform a backup.

Every Sunday morning, at 03:00, the server will reboot. Don't worry, though. The server usually only takes about 2-3 minutes to reboot.

On the last day of every month, we reboot our routers, switches, etc. To make matters worse, I also perform maintenance on the server and install any updates that are needed. So from 21:00 to, like, hopefully no later than 22:00, connections to our website will be really spotty.

Yes, I know everything is in 24-hour time. I like it better that way. Just do the math.

Random Outages

As I stated earlier, stuff happens. Sometimes we need to reboot a router or the server, or the server will have an error. If the server goes out for a long time, that means something really bad happened. Check back in occasionally. If you are on the mailing list, you will get regular updates on such outages.
